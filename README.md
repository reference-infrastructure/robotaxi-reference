# Robotaxi Reference Framework

This repository contains the **reference-infrastructure layer**
for the website **Robotaxi.de**.

It provides a frozen, vendor-neutral, source-bound framework
for the structured analysis of autonomous mobility and robotaxi systems.

This is **not** a product repository.
This is **not** an implementation guide.
This is **not** a policy recommendation.

It is a **reference asset**.

---

## Purpose

The purpose of this repository is to:

- document a stable analytical framework for robotaxi systems
- provide machine-readable and human-readable authority signals
- mirror the published reference state of Robotaxi.de
- enable auditability, comparison and long-term consistency

The repository is designed as a **reference layer**, not as a living blog
and not as a continuously evolving codebase.

## Scope and Boundaries

The analytical scope is strictly limited to:

- autonomous road-based passenger transport (robotaxis)
- regulatory, technical, economic and societal system dimensions
- publicly documented standards, laws and authority publications

Out of scope are:

- investment advice
- vendor rankings or recommendations
- implementation instructions
- speculative forecasts
- unpublished or proprietary materials

Details are defined in `SCOPE.md`.

---

## Methodological Principles

All content follows these principles:

- source-first (normative and primary references only)
- vendor-neutral
- audit-oriented
- system-level perspective
- explicit uncertainty where applicable

The full methodological framework is defined in `METHODOLOGY.md`.
