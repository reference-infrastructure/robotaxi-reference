## Freeze Definition

“Freeze” means:

- All core content is finalized in structure and meaning
- No semantic changes without a new release ID
- Only non-substantive changes allowed:
  - image replacement
  - alt text completion
  - layout or styling adjustments
  - accessibility improvements
  - minor wording clarifications **without meaning change**

After the freeze:
- analytical scope
- terminology
- structure
- source set

are considered **stable**.

## Versioning Policy

Version format follows **semantic versioning**:

`MAJOR.MINOR.PATCH`

- **MAJOR** — structural or conceptual changes
- **MINOR** — content extensions within the same framework
- **PATCH** — corrections without analytical impact

Release `1.0.0` denotes:
- first complete framework
- internally coherent reference state
- baseline for future comparison

---

## Change Policy After Release

After Release 1.0.0:

Allowed without new release:
- formatting corrections
- typo fixes
- accessibility metadata
- repository metadata (topics, badges)

Requires new release:
- new sources
- removed or replaced sources
- new analytical sections
- changed conclusions or interpretations
- altered methodological scope

All substantive changes require:
- version increment
- updated release date
- documented rationale
